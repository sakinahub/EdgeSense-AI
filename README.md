# EdgeSense AI

### Edge AI-Based Predictive Maintenance for Industrial Machines

## Overview

EdgeSense AI is an Edge AI-based predictive maintenance system designed to monitor the health of industrial machinery and detect potential machine anomalies.

The project uses machine data to identify abnormal behavior and provides a dashboard for monitoring machine health and fault conditions.

The main idea behind EdgeSense AI is to move intelligent monitoring closer to the machine, reducing the dependency on cloud-based processing and enabling faster anomaly detection.

---

## Problem Statement

Unexpected machine failures can lead to production downtime, maintenance costs, and operational losses.

Traditional maintenance approaches often depend on scheduled maintenance or manual monitoring, which may not detect developing faults early.

EdgeSense AI explores how Machine Learning and Edge AI can be used for predictive maintenance by continuously analyzing machine-related data and identifying abnormal patterns.

---

## Key Features

- Real-time machine monitoring dashboard
- Machine health monitoring
- Predictive maintenance
- Machine anomaly detection
- Fault type visualization
- Recent activity monitoring
- Simulated fault detection
- Machine Learning-based prediction
- Edge AI architecture
- Interactive Streamlit interface
